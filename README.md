# Tablero Kanban

Aplicacion web de gestion de tareas basada en un tablero Kanban.

## Funcionalidades

- Crear tareas.
- Editar tareas.
- Eliminar tareas.
- Drag & Drop entre columnas.
- Estadisticas de tareas.
- Sistema de comentarios.
- Asignacion de responsables.
- Etiquetas.
- Filtros por prioridad, etiqueta y responsable.
- Busqueda de tareas.
- Columnas dinamicas.
- Diseno responsive.
- Menu hamburguesa.

## Tecnologias

- HTML5
- CSS3
- JavaScript Vanilla
- SortableJS
- json-server
- Git
- GitHub
- GitHub Pages

## Instalacion

Clonar el repositorio:

git clone https://github.com/ainaragrcgrc-coder/tablero-kanban.git

Entrar en la carpeta:

cd tablero-kanban

Instalar dependencias:

npm install

## Ejecutar

Iniciar json-server:

npm start

Abrir en el navegador:

http://localhost:3000

## API

http://localhost:3000/tasks

http://localhost:3000/users

http://localhost:3000/comments
